# AutoPointUA

**AutoPointUA** — інформаційна система для купівлі та продажу автомобілів, розроблена на платформі Universal Windows Platform (UWP) із використанням C# та хмарних сервісів Firebase.

Проєкт призначений для автоматизації процесів розміщення автомобільних оголошень, управління інформацією про транспортні засоби та організації взаємодії між покупцями, продавцями й адміністраторами.

## Мета проєкту

Метою розроблення AutoPointUA є створення зручної інформаційної системи для організації процесів купівлі та продажу автомобілів.

Система забезпечує централізоване зберігання даних, автентифікацію користувачів, розмежування прав доступу та управління автомобільними оголошеннями.

## Основні можливості

Система передбачає роботу з трьома основними категоріями користувачів:

### Покупець

- Перегляд автомобільних оголошень.
- Ознайомлення з характеристиками транспортних засобів.
- Пошук автомобілів за доступними параметрами.
- Взаємодія з функціональними можливостями платформи.

### Продавець

- Розміщення автомобільних оголошень.
- Додавання інформації про транспортні засоби.
- Редагування та видалення оголошень.
- Управління власними пропозиціями.

### Адміністратор

- Управління користувачами.
- Модерація автомобільних оголошень.
- Контроль інформаційного наповнення системи.
- Адміністрування основних процесів платформи.

## Архітектура системи

Архітектура AutoPointUA побудована на основі трирівневого підходу, який передбачає розділення системи на такі рівні:

1. **Рівень представлення (Presentation Layer)** — відповідає за користувацький інтерфейс та взаємодію користувача із системою.
2. **Рівень бізнес-логіки (Business Logic Layer)** — забезпечує обробку запитів, виконання операцій та реалізацію основних правил функціонування системи.
3. **Рівень доступу до даних (Data Access Layer)** — відповідає за взаємодію з Firebase, отримання, збереження, оновлення та видалення інформації.

Розділення відповідальностей між рівнями спрощує супровід програмного забезпечення, тестування окремих компонентів та подальше розширення функціональності.

Архітектурний підхід також передбачає ізоляцію окремих функціональних компонентів, що створює передумови для масштабування системи та незалежного розвитку її складових.

### Структура рішення

Рішення Visual Studio містить два основні проєкти:

- `AutoPointUA` — основний UWP-застосунок, який забезпечує користувацький інтерфейс та взаємодію з функціональними компонентами системи.
- `AutoPointUA.Core` — окремий проєкт для розміщення спільної логіки застосунку.

Файл `AutoPointUA.sln` об'єднує проєкти в єдине рішення Visual Studio.

## Інтеграція з Firebase

Для організації хмарного зберігання та обробки даних використовується платформа Firebase.

Взаємодія UWP-застосунку з хмарними сервісами здійснюється за допомогою REST API.

Основні напрямки інтеграції:

- **Firebase Authentication** — автентифікація користувачів та управління їх обліковими записами.
- **Хмарне зберігання даних** — централізоване збереження інформації, необхідної для роботи системи.
- **REST API** — передавання запитів та отримання відповідей від хмарних сервісів.
- **Обробка даних** — виконання операцій створення, читання, оновлення та видалення інформації.

Використання Firebase дозволяє організувати взаємодію клієнтського застосунку з хмарною інфраструктурою без необхідності розгортання власного серверного середовища для базових операцій із даними.

## Встановлення та запуск

### Необхідне програмне забезпечення

Для збирання та запуску проєкту необхідні:

- Windows.
- Visual Studio з підтримкою розроблення UWP.
- Windows SDK.
- .NET та необхідні компоненти розроблення.
- Доступ до Firebase.
- Налаштування Firebase Authentication та відповідних сервісів.

### Інструкція із запуску

1. Клонуйте репозиторій:

   ```bash
   git clone https://github.com/Pashurka/AutoPointUA.git
   ```

2. Відкрийте файл `AutoPointUA.sln` у Visual Studio.

3. Відновіть необхідні NuGet-пакети.

4. Перевірте налаштування підключення до Firebase.

5. Переконайтеся, що налаштовано необхідні параметри автентифікації.

6. Виберіть проєкт `AutoPointUA` як стартовий.

7. Зберіть та запустіть застосунок.
